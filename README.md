# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ完結型コーポレートサイトです。

> このサイトに登場する会社名、人名、住所、事例、数値、メールアドレスはすべて架空のものです。

## 概要

企画・設計・開発・運用までを一つのチームで担う、という設定の会社を紹介するページです。ページは次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| お知らせ | ナビゲーション下に最新のお知らせを1件表示 |
| ヒーロー | キャッチコピーと、窓の灯りが点るスカイラインのイラスト |
| 事業内容 | ビルのフロア案内板に見立てた5つのサービス(32F〜B1) |
| 導入事例 | 物流・小売・医療の3事例 |
| プロダクト | 監視・分析サービス「Beacon」の紹介 |
| 会社情報 | 会社概要の表とお知らせ一覧 |
| お問い合わせ | メールでの相談ボタン |

### 特徴

- HTMLファイル1つで完結しており、ビルドや依存パッケージのインストールは不要です
- ライトテーマとダークテーマの両方に対応しています(OSの設定に追従)
- スマートフォンの画面幅でもレイアウトが崩れないようにしています
- Webフォント(Google Fonts)を使うため、表示にはインターネット接続が必要です。接続がない場合はOS標準のフォントで表示されます

## ブラウザで開く手順

1. このリポジトリを取得します。

   ```
   git clone <リポジトリのURL>
   ```

   すでにフォルダーがある場合は、この手順は不要です。

2. `skyline-technologies.html` をブラウザで開きます。次のいずれかの方法を使ってください。

   - **ダブルクリック**: エクスプローラー(Finder)で `skyline-technologies.html` をダブルクリックすると、既定のブラウザで開きます
   - **ドラッグ&ドロップ**: ファイルをブラウザのウィンドウにドラッグします
   - **コマンドライン**: プロジェクトのフォルダーで次を実行します

     | OS | コマンド |
     | --- | --- |
     | Windows (PowerShell) | `start skyline-technologies.html` |
     | macOS | `open skyline-technologies.html` |
     | Linux | `xdg-open skyline-technologies.html` |

3. ページが表示されれば完了です。
